hitab 真实平均成本:direct=7、cot=708、sql=1309 tok(工具调用按 ×200 折算)。代入:
- direct(最便宜)= 0.3 × (7−7)/(1309−7) = 0.3 × 0 = 0
- cot = 0.3 × (708−7)/(1309−7) = 0.3 × 0.538 = 0.161
- sql(最贵)= 0.3 × (1309−7)/(1309−7) = 0.3 × 1 = 0.3

- 加 --all_paths(每题对 direct/cot/sql 各出一条样本,SFT 学"会执行三条路",选路交给 GRPO)和 --include_wrong(默认只留教师答对的路径,拒绝采样)。
- 实测 hitab v2:1500 题 → 保留 1215 题 → 3219 行(~2.6 行/题),三路分布 33%/34%/34% 均衡(对比旧 oracle 单选的塌缩式分布)。
- GRPO 侧按 (task, id) 去重 prompt,避免同题被重复采样;旧单 oracle 数据没有 path_cost 时奖励自动回退,不会报错。

0.3 是在配置里设的 max_cost_penalty 上限
